# Manual Testing Project – nopCommerce Demo Website

## Project Overview

This repository contains a complete Manual Testing project for the **nopCommerce Demo Website**. It demonstrates the complete Software Testing Life Cycle (STLC), from requirement analysis to test execution and reporting. The project includes professional QA documentation, test artifacts, and bug reports created during the testing process.

---

## Project Objective

The objective of this project is to verify the functionality, usability, and reliability of the nopCommerce Demo Website through comprehensive manual testing and proper documentation.
